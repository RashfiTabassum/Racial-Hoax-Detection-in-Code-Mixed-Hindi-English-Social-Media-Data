# Racial-Hoax-Detection-in-Code-Mixed-Hindi-English-Social-Media-Data
This project detects racial hoaxes in code-mixed Hindi-English social media data from a shared task dataset. We use MuRIL and IndicBERT transformers with techniques like contextual embeddings, class balancing, oversampling, and ensemble methods (averaging, weighted averaging, and stacking) for improved performance.
